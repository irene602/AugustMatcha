# August Matcha

August Matcha es una marca de matcha en desarrollo. La idea es crear un ritual cotidiano que una el matcha, el movimiento y el autocuidado, con una identidad visual delicada. El primer objetivo es probar un matcha envasado con marca propia. Los encuentros de pilates y los accesorios quedan para una fase posterior.

La web es una maqueta interactiva para revisar la marca y la presentación del producto. El envase que aparece es una propuesta visual. En la maqueta, el formulario de correo es de demostración y los pedidos aún están cerrados.

## Cómo trabajamos Irene y Ginés

Irene lleva las decisiones de marca, producto y lanzamiento. Ginés puede ocuparse del código y revisar la parte técnica. Irene puede pedir cambios en lenguaje normal, por ejemplo, «quiero que el logo se vea más grande en el móvil». Puede indicar qué parte de la web estaba viendo y adjuntar una captura si le resulta más fácil.

- **Para pedir o apuntar un cambio**, usa [Issues](https://github.com/irene602/AugustMatcha/issues). Cada ficha deja por escrito lo que hay que hacer.
- **Para revisar una propuesta**, usa [Pull requests](https://github.com/irene602/AugustMatcha/pulls). Ahí se ve qué se propone cambiar antes de incorporarlo a la versión principal. La descripción debe explicar qué se verá distinto y cómo comprobarlo.
- **Para ver lo que ya se ha incorporado**, consulta el [historial de cambios](https://github.com/irene602/AugustMatcha/commits/main/). Las decisiones que afecten al producto, al diseño o al lanzamiento también se reflejan en el plan.

El repositorio es público. Compartimos aquí el trabajo que se puede publicar. Conservamos en privado los presupuestos de proveedores, los datos personales, las contraseñas y cualquier dato de clientes.

## Para Ginés

La maqueta es HTML, CSS y JavaScript sin dependencias de instalación. Los recursos de la maqueta están integrados en `index.html`, incluido el material de campaña. El PNG de `branding/` es la pieza independiente para redes. Para revisar cambios de interfaz, abre el HTML en un navegador y comprueba cómo se ve en móvil y escritorio. Antes de modificar un archivo, revisa la versión principal y las propuestas abiertas para evitar solapar trabajo.
