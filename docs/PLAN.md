# Plan de August Matcha

Actualizado el 24 de noviembre de 2026.

| Tema | Estado |
| --- | --- |
| Marca | August Matcha es el nombre de trabajo. La idea une matcha, movimiento y autocuidado. |
| Versiones anteriores de la marca | [Logo coral con loto blanco](../branding/august-matcha-perfil-loto-blanco.png), [logo azul glaciar](../branding/august-matcha-perfil-azul-glaciar.png) y [maqueta de lata azul](../branding/august-matcha-lata-azul-glaciar.png). |
| Identidad final de la colección | **Daily Matcha** usa azul glaciar con loto blanco. **Ceremonial Matcha** usa rosa coral con loto burdeos. Los dos usan las letras burdeos del logo final. |
| Propuesta de packaging | Latas con la tapa burdeos a juego con las letras y estuches individuales en el color de cada línea. |
| Producto | El primer objetivo es un matcha envasado con marca propia. El proveedor, el envase final, el precio y la fecha de lanzamiento quedan por confirmar. |
| Web | La maqueta de colección, con las latas y los dos flyers, está en revisión visual. |

Para añadir una tarea concreta, abre una [ficha de trabajo](https://github.com/irene602/AugustMatcha/issues). Cuando haya una decisión confirmada, anótala aquí para que Irene y Ginés puedan consultarla.
